# Basant's Portfolio

A personal portfolio website built with React and Vite. This project showcases Basant's work, skills, and professional profile in a modern, responsive single-page experience.

## Live Demo

https://portfolio-theta-five-tz0auun8g4.vercel.app/

## Tech Stack

- React 19
- Vite
- GSAP for animations
- React Icons
- Vercel Speed Insights

## Features

- Responsive portfolio layout
- Animated UI and transitions
- Modern landing page experience
- Fast frontend performance with Vite

## Getting Started

### Prerequisites

- Node.js 18+ recommended
- npm

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

This starts the Vite development server, usually available at:

```bash
http://localhost:5173
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
